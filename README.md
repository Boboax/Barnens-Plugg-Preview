# Barnens Plugg – kvällslägret

Publik, fristående demo med fiktiva profiler och separat lokal lagring.

Spela: https://boboax.github.io/Barnens-Plugg-Preview/

Välj **Fyra vänner & 200 testmynt** för att prova alla djur, inredning och garderoben. Återställ med samma knapp om besökstiden tar slut.

Byggd från lägeruppdateringen i Boboax/Barnens-Plugg (PR #1). Detta repo innehåller endast den färdiga webbversionen och dess bilder; det publicerar inte barnens ordinarie spel.
